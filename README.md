# Group Chat Awards

A one-page, stats-based awards ceremony for our WhatsApp group (Feb 2025 – Nov 2026).

It's a single static `index.html` with no build step.

## Publish on GitHub Pages

1. Push this repo to GitHub.
2. In the repo, go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to "Deploy from a branch", pick `main` and `/ (root)`, and save.
4. The page is live at `https://<your-username>.github.io/group-chat-awards/` after a minute or so.

## Preview locally

Open `index.html` in a browser.
